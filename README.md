# Справочник контактов

Лабораторная работа № 1 «Разработка модели данных», вариант 4.
Десктопное приложение на JavaFX: просмотр, добавление, редактирование и импорт/экспорт контактов в CSV.

## Стек

| Компонент | Версия |
|---|---|
| Java | 21 (toolchain) |
| JavaFX (OpenJFX) | 21.0.12, модуль `javafx.controls` |
| Сборка | Gradle 9.6.0, Kotlin DSL |
| Тесты | JUnit 5 — пока не подключён, появится в лабораторной № 3 |

## Запуск

```bash
./gradlew run          # Linux / macOS
gradlew.bat run        # Windows
```

Требуется JDK 21 — Gradle подберёт его сам через `foojay-resolver-convention`.

## Структура

```
src/main/java/ru/contacts/
├── model/     сущности варианта 4 — не зависят ни от чего
│   ├── Contact             базовый контакт, неизменяемый
│   ├── CorporateContact    + должность, внутренний номер — единственный Editable-тип
│   ├── EmergencyContact    read-only, появляется только из файла
│   ├── Editable            контракт «контакт можно менять»
│   └── ContactType         enum: соответствие класс ↔ тег в CSV
├── io/        загрузка/сохранение CSV, не зависит от JavaFX
│   ├── CsvLoader           парсер и сериализатор
│   ├── CsvLoadResult       контакты + список ошибок по битым строкам
│   ├── CsvRowError         номер строки, код ошибки, сообщение
│   └── CsvErrorCode        коды: BAD_HEADER, WRONG_FIELD_COUNT, UNKNOWN_TYPE, …
└── ui/        JavaFX, программный интерфейс (без FXML и CSS)
    ├── ContactApp          главное окно, таблица, кнопки
    └── ContactDialog       добавление/редактирование корпоративного контакта
```

Зависимости идут строго в одну сторону: `ui → io → model`.

## Формат файла

CSV с разделителем `;`, UTF-8 **с BOM**, перевод строки `\n`:

```
type;name;phone;email;organization;position;internalNumber
CONTACT;Иван Петров;+7-900-111-22-33;ivan@example.com;ООО Ромашка;;
EMERGENCY;Мама;+7-900-000-00-01;mama@example.com;;;
CORPORATE;Анна Сидорова;+7-900-222-33-44;anna@corp.ru;ООО Ромашка;Менеджер;1234
```

Готовый пример с намеренно битыми строками — `src/main/resources/contacts.csv`.
Загрузите его через «Загрузить CSV»: 4 контакта загрузятся, 2 строки пропустятся с кодами ошибок.

Экранирование значений не поддерживается: `;` внутри имени приведёт к `WRONG_FIELD_COUNT`.

## Что реализовано

- иерархия из трёх типов и интерфейс `Editable`
- кнопка «Изменить» активна только для `Editable`-типов
- «Добавить» создаёт только редактируемый тип; базовый и аварийный — только из файла
- загрузка и сохранение CSV, битые строки пропускаются с кодом ошибки
- валидация полей в диалоге: пустое имя/телефон, e-mail без `@`, пустая должность
